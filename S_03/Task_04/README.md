# Домашнее задание 3.IV

Индивидуальный вариант из Classroom задан в `config.h`: `T1 = double`,
`T2 = int`, `M = 14`, `N = 2`.

Программа создаёт `array`, `vector`, `list` и `deque`, заполняет их случайными значениями из `[-N, N]`, один раз выбирает общий второй аргумент, применяет `modified::average<T2>` и переносит результаты в контейнеры других видов. Использованы индексный, итераторный и range-based циклы. Таблица из `M` строк записывается в `results.md`.

Сборка и запуск из этой директории:

```sh
c++ -std=c++17 -Wall -Wextra -Werror -pedantic main.cpp -o task_04
./task_04
```

Откройте `results.md` в Markdown-просмотрщике. Запуск перезаписывает таблицу
новыми случайными значениями. Дробная часть результата при преобразовании
к `int` отбрасывается.
