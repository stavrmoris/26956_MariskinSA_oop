# Задание 2, занятие 2

Реализации original::average и modified::average имеют одинаковую
сигнатуру и расположены в разных пространствах имен. Вторая реализация
добавляет случайное число от 1 до 100 с вероятностью 50 %. Вариант
by_reference::average демонстрирует изменение аргумента через ссылку.

Для сборки из этой директории:

    c++ -std=c++17 -Wall -Wextra -Werror -pedantic main.cpp -o task_02
    ./task_02

При запуске программа запрашивает сначала два целых, затем два вещественных
числа. Определения шаблонов находятся в head.h и mod_head.h, поэтому в
команду сборки включен только main.cpp.
